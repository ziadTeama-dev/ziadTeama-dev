## 🚀 Featured Projects

### 🧠 [MoE Image Captioning](https://github.com/ziadTeama-dev/moe-image-captioning)

A custom image-captioning system combining **ResNet-50 + Transformer + Mixture-of-Experts** with noisy routing and confidence-based early exit.

**Highlights**

* 3 experts with Top-1 routing
* Shared expert + noisy router
* Confidence-based early exit
* BLEU-1 / BLEU-4 evaluation
* ~23% lower evaluation time in the reported early-exit experiment

**Stack:** `PyTorch` `Transformers` `MoE` `Computer Vision` `Streamlit`

---

### 🔥 [GPT Mini — From Scratch](https://github.com/ziadTeama-dev/gpt-mini-from-scratch)

A decoder-only GPT implementation built **from scratch in PyTorch**, including custom attention, normalization, autoregressive generation, and regularization experiments.

**Stack:** `Python` `PyTorch` `Transformers` `TensorBoard` `Streamlit`

---

### 🎨 [DDPM From Scratch](https://github.com/ziadTeama-dev/pytorch-ddpm-from-scratch)

An end-to-end implementation of **Denoising Diffusion Probabilistic Models** using a custom U-Net, sinusoidal timestep embeddings, and iterative reverse diffusion.

**Stack:** `PyTorch` `Computer Vision` `Deep Learning` `Jupyter`

---

### 💬 [Qwen2.5 LoRA Fine-Tuning](https://github.com/ziadTeama-dev/qwen2.5-lora-finetuning)

A conversational AI application built by fine-tuning **Qwen2.5-1.5B-Instruct** with LoRA, 4-bit quantization, and Unsloth, then deploying it with Streamlit.

**Stack:** `PyTorch` `Hugging Face` `LoRA` `QLoRA` `Unsloth` `Streamlit`

### ⚽ [Football AI Agent](https://github.com/ziadTeama-dev/Football-AI-Agent-with-Unity-ML-Agents)

A reinforcement learning football environment where an agent learns through **PPO, reward shaping, and self-play** using Unity ML-Agents.

**Stack:** `C#` `Unity` `ML-Agents` `Reinforcement Learning`

### 📊 [IMDb ETL Pipeline](https://github.com/ziadTeama-dev/imdb-etl-pipeline)

An end-to-end data pipeline that extracts, transforms, and loads IMDb data into PostgreSQL using **Apache Airflow**, with a web dashboard for exploration.
